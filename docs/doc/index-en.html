The Ontology for Preclinical Trials in Radiation Oncology (PTRO), is a domain-specific ontology designed to integrate SEND-standardized preclinical data using semantic web technologies. PTRO incorporates the Semantic Types Ontology (STY) as a framework for broad concept categorization.
